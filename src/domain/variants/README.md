Game variants, one folder each: `hexa-lines/`, `hexa-fit/`, `hexa-sort/`, `hexa-merge/`. Each folder holds the factory of its variant, which implements the engine `IVariantFactory`. A variant may import `src/domain/engine/` and its sibling folders `src/domain/shared/`, `src/domain/progress/` and `src/domain/achievements/`, never another variant folder, and never React, React Native or Expo.
