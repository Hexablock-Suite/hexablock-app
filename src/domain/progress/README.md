Progress of the player and the level catalog. It holds `GameProgress`, the progress models (`IProgressModel`, `GameResult`, `ProgressRecord`, `HighScoreProgress` and `LevelProgress` with `ILevelStars`), `LevelStatus`, `LevelDefinition`, `ILevelBuilder`, `LevelId` and `Stars`. It imports only `src/domain/shared/` (rule `progress-imports-only-shared`), and never React, React Native or Expo. The engine names `IProgressModel` in `IVariantFactory.createProgressModel()`, so each variant factory gives the progress model of its game (decisions 31 and 64 of `docs/architecture/classes.md`).
