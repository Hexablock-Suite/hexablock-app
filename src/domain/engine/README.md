Generic engine: the game loop. It holds the board, the coordinates and the geometry families, the pieces and the piece sources, the turn, the phases, the rule and scoring contracts, the history, the timer, `GameFactory` and `IVariantFactory`. It may import only `src/domain/`, never `src/domain/variants/`, and never React, React Native or Expo. It imports the leaves of `src/domain/shared/`. Its one import of `src/domain/progress/` is the type `IProgressModel` in `variant-factory.ts`, because `IVariantFactory.createProgressModel()` gives the progress model of a game (decisions 31 and 64 of `docs/architecture/classes.md`).
