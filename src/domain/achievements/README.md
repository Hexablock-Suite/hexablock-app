Achievements: `AchievementCount`, `AchievementCounters`, the goals of `achievement-goal.ts` (`AchievementGoal`, `LevelsWon`, `EveryLevelWon`, `BestCountReached` and `TotalCountReached`) and `CountsForAchievements`, the capability of an event that counts for the achievements (#406). It imports only `src/domain/shared/` and `src/domain/progress/` (rule `achievements-imports-only-shared-and-progress`), and never React, React Native or Expo. Only the variants import it: an event of a variant that counts for an achievement implements `CountsForAchievements` and records its own count in `AchievementCounters`. No other folder of `src/domain/` imports it (decisions 60 and 64 of `docs/architecture/classes.md`).
